# Sigmar AOS — Complete Assurance Mockups

Comprehensive desktop mockups derived from the approved Sigmar Assurance Framework proposal in https://github.com/davidoabile/apcce/pull/69. The PR and repository content were not modified.

Every mockup has one standalone HTML source and one separate full-resolution PNG/JPG. Images illustrate structure and representative data only, not working backend functionality.

| Mockup | Approved process covered |
|---|---|
| 01 Assurance lifecycle | Seller claims → observation → verification → Blackboard → justified change → compilation → retesting → release |
| 02 Adaptive outcome contract | Reused identity/KYC, industry profiles, outcomes, targets, baseline, limits, methods |
| 03 Evidence provenance | References, ACL/classifications, provenance, hashes, independent evaluation records |
| 04 Worker studio | HTQL CLI, FLOW authority, holdouts, test methods, verdicts and non-provable claims |
| 05 CustomerCareGuild monitoring | Four observation channels, consent, continuous telemetry and evaluation triggers |
| 06 Blackboard root cause | Root-cause decision tree, finding, evidence sufficiency, no automatic source change |
| 07 Controlled improvement | Persona/Guild source changes only after evidence, approval, version diff and guardrails |
| 08 Recompile/retest/release | New DNA version, regression and holdouts, privacy gates, license continuity and rollback |
| 09 Enterprise portfolio | Multi-industry policies, role separation, audit, risk tiers and governance inheritance |
| 10 Marketplace disclosure | Claim-specific outcomes, proven and unproven ratings, version rights and protected IP |

**Colour and design:** Based on prior approved light admin visual language: charcoal (#28231f) topbar, warm cream workspace (#fffaf6), restrained orange (#e86f1c) accents, left navigation.

**Single source:** `sigmar-investment-app/docs/sigmar-assurance-framework.md` on PR #69; these are visual mockups, not separate competing requirements.
