# Project governance

Approved first sample adapted to seven layouts and both themes. Full-scroll SVGs on smaller devices. Editable vectors and embedded Satoshi. Illustrative access levels and grants; no live actions. Redundant AI account checkbox removed to prevent contradictory permission states. Root projects inherit workspace policy; invitations are planned, not accepted. Read/write examples are identical on all layouts.
