# macOS Settings first visual review

[Open SVG](01-settings-macos-light-v1.svg) · [Open in gallery](../global-mockups/index.html#macos/settings/light)

The user approved the researched settings structure and requested macOS first. This is one light macOS utility-window sample, 1200 × 920 logical units, opening Privacy & AI access. The eight approved sections appear in the sidebar; the complete linked adaptations now live in `admin/settings-mockups/`.

The window includes settings search, member scope, read/proposed-change rules, protected safeguards, connected-client state, Persona-scoped grants, access review and separate learning/source permission routes. It uses the approved Satoshi fonts and original logo, cool neutral light surfaces, fine borders and restrained copper details. A dedicated settings window has no conversation composer.

All client names, permission states and account identity are illustrative. Read access is enabled in this example so the active scoped client has a coherent effective grant; proposed changes are off. This is not a change to the source system's default-deny rules or any live account. Access changes require confirmation; Flow, Persona and policy requirements remain in force. Revoke and detailed confirmation states have not yet been designed. SVG controls illustrate intended targets; they do not operate an account.

The global gallery's macOS/light Settings entry points to this first sample. Other Settings compositions are explicitly labelled as earlier layouts.
