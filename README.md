# Sigmar interface designs

Native Sigmar AOS and authentication/onboarding mockups, with the approved branding, typography and DNA backgrounds.

## Review

After cloning the repository, open [admin/index.html](admin/index.html) in a browser. The [SVG gallery](admin/svg-mockups/index.html) brings together 71 screens across native platforms, light/dark themes and phone/tablet layouts. The HTML gallery works locally without a development server.

- [Complete SVG gallery and flow notes](admin/svg-mockups/README.md)
- [Personal and business account setup](admin/login-register/account-flows/README.md)
- [Shared mockup requirements](MOCKUP_REQUIREMENTS.md)
- [SVG verification](admin/svg-mockups/verification.json)

SVGs are the current review format. Existing raster references and older exports are retained as design history. New work should not export duplicate raster versions unless requested.

The gallery previews are static designs with illustrative data. They do not implement native authentication, account provisioning, microphone capture or backend permissions.

## Updating

Read [AGENTS.md](AGENTS.md) and the shared requirements before editing. Existing builders document environment-specific font and rendering dependencies. The current SVG-only generation and verification steps are in the gallery README; historical raster-export builders are retained for reference.
